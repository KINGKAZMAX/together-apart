# 临时公网部署记录

2026-10-26，已将生产构建通过 localhost.run 的免费 HTTPS 隧道公开：

[打开 Together, Apart](https://4fbb40b888a753.lhr.life)

一人创建房间后，通过 **Invite → Copy link** 分享含房间代码的链接；其他人填写名字加入同一房间。每个房间最多 6 人。

已完成公网入口验证：HTTPS 页面及健康检查成功；Chromium 通过公网地址建立 3 个带页面来源的 WebSocket 连接，创建／加入同一房间、角色坐标广播、表情广播、文字聊天同步通过。该项检查只覆盖公网房间同步，不代表不同实际网络之间的音视频已经全部验收。

生产服务运行在本机 `127.0.0.1:5190`，与开发服务分开；生产 Node 服务和 SSH 隧道均已在独立后台进程中运行。状态及诊断记录位于 `output/public-demo/`，该目录不提交 Git。

此地址是临时演示入口，依赖本机开机、联网、现有系统代理及后台进程。电脑睡眠、隧道退出或网络中断会导致入口不可用；重新建立免费隧道可能更换地址。当前没有创建固定云主机或购买资源，也未配置 TURN 凭据，因此复杂防火墙或 NAT 环境仍可能影响音视频连接。

重建与运行方法见 [临时公网会议入口](PUBLIC-DEMO.md)，稳定部署方法见 [部署说明](DEPLOYMENT.md)。
