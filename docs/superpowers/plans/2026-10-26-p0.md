# Together, Apart P0 实现计划

**目标：** 浏览器中进入等距工作坊，以真实摄像头的点头、鼓掌、举手触发角色头顶 3.5 秒表情；使用许可明确的可爱开源模型。

**架构：** React 管理界面与媒体状态；Three.js 场景管理角色、移动、气泡；MediaPipe Face + Hand 产生关键点，独立时序检测器产生动作事件。识别只在用户开启时运行，手动来源单独标记。

**技术栈：** React 19、Three.js、Vite 8、MediaPipe tasks-vision；沿用 AI Office MIT 基础和适合的场景组件，角色另引入 CC0 资源。

- [x] 原型基础：保留许可、配置本地模型/WASM、创建统一接口。
- [x] 识别：src/vision/gesture-engine.js 纯函数状态机与 node:test；src/vision/camera-controller.js 媒体和推理生命周期。
- [x] 场景：src/scene/WorkshopScene.js；createWorkshopScene(container,{onMove}) 返回 react(type,{source}), setName(name), reset(), update(dt), render(), getState(), dispose()；type 为 nod/clap/raise。
- [x] 角色资源：public/models/characters.json 与本地 GLB，逐项来源与许可证，失败时提供可用简化人物。
- [x] 界面：src/App.jsx、src/index.css；开启/关闭摄像头、校准、三动作说明、可控人物、来源可见。
- [x] 集成：camera-controller 的 onReaction({type,source:"camera",timestamp}) 接场景 react；onStatus({state,message,metrics}) 更新界面。start(videoElement)、stop()、calibrate()、dispose()。
- [x] 验证：动作状态机正负例、拒绝权限/关闭/重试、气泡跟随与3.5秒过期、键盘移动；Vite build；网页游戏 Playwright 脚本与截图检查。
- [x] 真摄像头验收：2026-10-26 用户确认「三种动作都能触发」。本次设备与环境下的点头、鼓掌、举手功能验收通过；不外推为跨用户、跨光照的准确率结论。

视觉方向：明亮低饱和的薰衣草与薄荷工作坊，柔和地面与圆角家具，可爱人物为主体；UI 保持轻量，右侧相机与动作说明，底部简短操作提示。
交互：点击地面/方向键移动；反馈气泡弹出并轻浮；被摄像头识别的动作给出清晰但克制的状态提示。
