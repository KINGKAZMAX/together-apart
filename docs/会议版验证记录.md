# 会议版验证记录

日期：2026-10-26。版本：0.2.0。

## 已验证

- Node 自动化测试：56/56 通过。覆盖三动作状态机、摄像头共享流归属、取消与释放、媒体协商、房间隔离与人数限制、真实 WebSocket。
- ESLint 与 Vite 生产构建通过。构建有 Three.js 共享块大于 500 KB 的非阻断提示。
- 两个独立 Chromium 会话：完整邀请链接加入、真实参与者替代示例、聊天、三种表情绑定正确远端角色及自动消失、移动同步、会中 EN/ZH 切换。
- 本机摄像头识别模型初始化；仅开启 Gestures 时不广播摄像头。显式 Camera 后复用同一采集流。
- WebRTC 浏览器测试：双向 sendrecv，双方收到音频包、已解码视频帧并播放远端视频。测试输入为 Chromium 合成摄像头/麦克风，不是真人画面。
- 屏幕共享使用合成 canvas 作为测试输入，远端收到共享画面；停止后恢复摄像头并保留麦克风；离开后远端头像和 PeerConnection 清理。
- 公网 HTTPS 与三个浏览器 WebSocket 客户端：入会、坐标、表情、聊天同步通过。见 `docs/公网部署记录.md`。
- develop-web-game 提供的 Playwright 客户端执行完成，证据 `output/meeting-web-game/`。

## 证据与边界

本地证据（不提交运行截图至 Git）：

- `output/media-browser-check/diagnostics.json`：双向 WebRTC SDP、流与 RTP 统计。
- `output/meeting-smoke/03-two-person-call.png`：两个实际浏览器的合成视频会议。
- `output/public-demo/public-smoke.json`：公网三人同步记录。

完整会议脚本的多人、媒体、共享与离开检查均执行通过；最后在保留两个 3D 页面的情况下新开手机页面，软件 GPU 加载超过 30 秒，脚本因此退出 1。手机布局另行独立检查，避免把该次脚本报告为全绿。

真人三动作功能在 P0 阶段由用户确认“都能触发”；本轮保留识别核心。没有测量跨设备准确率，也没有完成不同运营商/NAT 的音视频实测。尚未配置 TURN，中继要求取决于双方网络。

公开地址为临时隧道，依赖本机服务、代理和电脑在线，不代表已迁至长期云主机。

手机独立验证：390px 页面无水平溢出，个人资料弹窗可操作，帮助页不含许可证跳转。证据 `output/meeting-smoke/mobile-results.json`。
