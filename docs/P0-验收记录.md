# Together, Apart P0 验收记录

验收日期：2026-10-26。范围为本地网页交互演示，角色使用用户选定的四个 Kenney CC0 模型。

## 真人摄像头反馈

在请求用户开启摄像头、校准并依次完成三个动作后，用户明确回复：**「三种动作都能触发」**。

| 动作 | 对应头顶反馈 | 结果与依据 |
| --- | --- | --- |
| 点头 | ✨ 柔和发光 | 通过，用户真人测试反馈 |
| 鼓掌 | 👏 闪光鼓掌 | 通过，用户真人测试反馈 |
| 举手 | ❓ 问题图钉 | 通过，用户真人测试反馈 |

这是本次用户设备与环境下的功能验收。助手未直接观察真人视频；未记录重复次数、准确率、延迟、设备型号或光照条件，故不推导这些指标。

## 已完成的工程验证

- 23 项动作状态机与摄像头控制器测试通过，覆盖正常动作、噪声、冷却、遮挡、连续举手、权限拒绝、取消与资源释放。
- 浏览器验证三种手动反馈、气泡 3.5 秒过期、键盘移动、输入名字与弹窗期间的移动抑制。
- 本地 MediaPipe 模型与 WASM 真实初始化、推理及关闭资源流程经过合成视频验证；该测试与上述真人反馈分开记录。
- 四个角色加载及五种预览动画可用；390 px 手机布局无水平溢出。
- 构建与 lint 成功；构建产物附有素材和依赖许可。
