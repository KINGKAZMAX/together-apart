# 更圆润的角色候选（预览阶段）

核验日期：2026-10-26。以下是两套作者原创、许可明确的替代资源；“接近动森”仅描述圆润大头、友好的视觉方向。任天堂《动物森友会》的原作提取模型不在本清单中，也没有被视为开源资产。

## 1. Mini Simple Characters | Free Demo — Joao Baltieri

优先推荐给当前工作空间：圆润大头、简单眼睛、较小的四肢，服装和头发可以组合。官方交互 demo 支持拖动旋转、换部件、改色与预设切换，用户可以先直接体验。

- 官方交互预览：https://joaobaltieri3d.itch.io/mini-simple-characters-demo
- 官方产品与许可页：https://www.joaobaltieri.com/product-page/mini-simple-characters-free-demo
- 官方产品预览原图：https://static.wixstatic.com/media/70de1d_212e2531e74b4283bc7df4ddbc2cdc10~mv2.jpg
- 本地预览：`public/models/alternatives/mini-simple-official-preview.jpg`
- 明确许可：产品页 Licence 栏链接到 Creative Commons CC0；itch 官方 demo 的 Asset license 也标为 Creative Commons Zero v1.0 Universal。
- 产品页列出的格式：FBX、PNG（256 px）；动作：Idle、Walk、Run、Jump、Loose；另有 Angry / Sad 面部 blendshapes。
- 获取情况：本轮只保存官方预览。官网显示价格 R$0.00 和购物车入口；未走结账流程，未声称本地已有可运行 GLB。其 Free Demo 许可不外推至作者其他收费产品。

## 2. Platformer Game Kit — Quaternius

更偏小动物方向：使用包中的蓝色兔子角色。短四肢、大头和简单面部，与暖色工作空间比较容易搭配；官方整包预览左侧可见该角色。该包的环境仅为展示背景，不是此次替换范围。

- 官方资源与许可页：https://quaternius.com/packs/ultimateplatformer.html
- 作者官方 itch 页：https://quaternius.itch.io/ultimate-platformer-pack
- 官方预览原图：https://quaternius.com/assets/images/fullres/ultimateplatformer.jpg
- 本地预览：`public/models/alternatives/platformer-official-preview.jpg`
- 明确许可：这个具体资源页的 License 栏为 CC0，直接指向 https://creativecommons.org/publicdomain/zero/1.0/ 。官方 itch 页面也写明 CC0、可用于商业项目。
- 格式：FBX、OBJ、glTF、Blend；主角色含 18 个动画（来自官方说明）。
- 获取情况：本轮只保存官方预览，未下载或接入新角色 GLB。许可依据是此旧资源包的具体 CC0 标注，不是网站的其他通用许可页面。
